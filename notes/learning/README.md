# Learning guides

These guides explain what the user ran, what the assistant added, and how the current development environment works. Read in this order or open the topic you need:

1. [Tools and workspace](01-tools-and-workspace.md): Node, pnpm, workspaces, project files, commands, and what was installed.
2. [Frontend and data flow](02-frontend-and-data-flow.md): how the browser starts, what the counter does, and how a future API will connect to the database.
3. [Local database](03-local-database.md): Docker, port 5434, persistent data, credentials, daily commands, and what each check proves.
4. [Git and safe synchronization](04-git-and-safe-sync.md): changes, staging, commits, pushing, and safe history.

Use [current progress](../progress/README.md) for what is verified now, and [findings](../findings/README.md) before making decisions based on earlier work. These pages explain concepts; they do not replace the dated verification record.

Future topics should receive their own files, for example `05-identity-and-sessions.md` once that feature exists. Add a link here and update existing explanations when implementation changes their behavior.
